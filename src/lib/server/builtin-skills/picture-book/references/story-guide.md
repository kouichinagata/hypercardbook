# ストーリーの作り方

## 対象年齢ごとの目安
| 年齢 | 1ページの文章 | 語彙・表現 |
|---|---|---|
| 0〜2歳 | 1文・10文字前後 | 擬音・くり返し・やさしい名詞。「ぽん」「ころころ」 |
| 3〜5歳 | 1〜3文・40〜80文字 | ひらがな中心。短い会話。くり返しのリズム |
| 6〜8歳 | 3〜6文・100〜200文字 | 漢字は学年相当まで。気持ちの言葉、少し長い展開 |
| 9歳〜 | 5〜10文 | 比喩・余韻。複雑な心情 |
英語など他の言語も、同じ考えで語彙と文の長さを合わせる。

## 起承転結
- **起**（約25%）：主人公、場所、小さな願いや日常。
- **承**（約25%）：出来事が起き、旅や試みが進む。小さなくり返しで期待を作る。
- **転**（約25%）：山場。予想外、困難、発見。**見開き（③）の最大の見せ場**。
- **結**（約25%）：解決と余韻。最後のページで、ほっとする、ふふっと笑う、考えさせる。

## 大切にすること
- 登場人物の性格・口調・好きなものを最初に決め、最後まで守る。感情の変化が見えるように書く。
- ページをめくる楽しさ：ページの終わりで「何だろう？」を作り、次のページで答える。ときどき、めくると世界が広がる。
- 驚きは1冊に1〜2回。余韻は最後の1ページに。
- 文章は声に出して読む（読み聞かせ）。句読点でリズム、くり返し、オノマトペ。
- 絵が語れることは文章で言わない。文章と絵が補い合う（文章「だいすき」、絵では抱きしめている）。
- 道徳を説教しない。

## 先に作る台帳（頭の中で）
ページ（ユニット）ごとに：何が起きる／type（single・multi・wide・文章だけ）／文章／絵の内容（場所・時間・キャラ・視点）／前後との連続（同じ小道具や時間帯）。
