# ページ構成の4パターン

**本は `layout: full`**：絵はページ全面に表示される。文章は絵の上に重ねて置く（下の `pb-page` の書き方。1つの `<div>` を1行で書き、中に空行を入れない）。文章だけのページは `pb-textpage`。

本は「左ページ・右ページ」の見開きで読まれる。カードは `***` で区切り、**奇数番目が左ページ、偶数番目が右ページ**。
物語に合わせて自動で選び、組み合わせる。ユーザーの指定があれば最優先。

| 型 | type | 使う場面 | 向かない場面 |
|---|---|---|---|
| ① 通常ページ | single | 基本。1ページに1つの場面。日常、出会い、会話 | 時間の経過を見せたいとき |
| ② 複数場面 | multi | 時間の経過、連続した動作、感情の変化（眠る→目覚める→窓を見る）。2〜4場面。**動作や感情が動く場面は優先して使う** | 動きのない説明、壮大な風景（wide へ） |
| ⑤ まとめ描き（標準） | grid | 普通のページの絵。1枚の画像に別々のページの絵を4つ（または2つ）描き、切り分ける | 山場（single / wide にする） |
| ③ 大きな見開き | wide | 壮大な風景、感動、驚き、クライマックス。1冊に1〜3回まで | 説明、会話 |
| ④ 左に絵・右に文章 | single + 文章だけのカード | 文章をじっくり読ませたい場面（物語の説明、会話、詩的な文章）。左右を逆にしてもよい | 動きの多い場面 |

## 目安の配分（16ページ＝見開き8つ、絵は厳選して8〜10枚）
起：①②を中心に導入／承：①と④／転：③で山場を大きく見せる／結：①と④で静かに余韻。②は1〜3回。
絵が要らないページは文章だけのカード（pb-textpage）にする。似た場面は ② にまとめて枚数を減らす。

## ① 通常ページ（single）
- ユニット1つ（type: single）、絵は縦長1枚。絵の下に短い文章（1〜3文）をMarkdownで書く。
- 絵には空・地面・壁など、**静かな余白**を作る（システムが指示する）。
```
<div class="pb-page"><img src="{{UNIT_3}}" alt=""><p class="pb-text">くまは そっと ドアを あけました。</p></div>
```

## ② 複数場面（multi）
- ユニット1つ（type: multi）、scenes に **2〜4個** の場面を読む順に書く。1枚の絵として自然につながる構図にする。
- コマ割りは均等な四角にしない。大きさ・形・配置を変える（大1つ＋斜めや丸みのある小さい場面）。境界はやわらかく。強い黒枠・吹き出しは使わない。
- composition に、場面の大きさ・形・配置を言葉で書く。例：`One large rounded scene on the left half, two smaller diagonal scenes stacked on the right; soft painted borders.`
- 文章は絵の下に、時間の流れが伝わるように短く。

## ③ 大きな見開き（wide）
- ユニット1つ（type: wide）。**左ページ（奇数番目のカード）から始める**。システムが横長で1枚描き、中央で左右に切る。
- 左のカードに `{{UNIT_n_L}}`、右のカードに `{{UNIT_n_R}}`。
- 中央の綴じ目に人物・顔・大事な物を置かせない（システムが指示する）。composition に、主役を左寄りか右寄りに置くことを書く。
- 文章は短く。左右どちらかのページの下に1〜2文、または絵だけにして次のページへ。
```
<div class="pb-page"><img src="{{UNIT_5_L}}" alt=""></div>

***

<div class="pb-page"><img src="{{UNIT_5_R}}" alt=""><p class="pb-text">わあ、きれい！</p></div>
```

## ④ 左に絵・右に文章
- 左カード：絵（ユニットは single）。右カード：**文章だけ**（絵なし）。
- 逆にするときは、左カードを文章だけ、右カードを絵にする。
- 文章は長めでもよい（対象年齢の上限まで）。改行と空行で読みやすく。詩的な文章は1行を短く。
```
<div class="pb-page"><img src="{{UNIT_6}}" alt=""></div>

***

<div class="pb-textpage"><p class="pb-body">おばあちゃんは ゆっくり はなしはじめました。<br>「むかし むかし、この もりには…」</p></div>
```

## 組み合わせの注意
- 同じ型を3回以上続けない。
- 見開き（③）や④の前後で、カードの奇数/偶数がずれないよう、必要なら文章だけのカードで調整する。
- 最初のカードは左ページ。最後は「おしまい」の余韻のある1ページ。


## ⑤ まとめ描き（grid）— 標準
- ユニット1つ（type: grid）、scenes に **ちょうど2つか4つ**。1つが1ページの絵。**ページ順**（左上→右上→左下→右下）に書く。
- カードごとに `{{UNIT_n_1}}`〜`{{UNIT_n_4}}` を使う（n はユニット番号）。
- 各ページは独立した完全な絵。枠線や余白は描かせない（システムが等分に切る）。
- 例（ユニット3、ページ5〜8）：
```
<div class="pb-page"><img src="{{UNIT_3_1}}" alt=""><p class="pb-text">…</p></div>
```
  （ページ6は `{{UNIT_3_2}}`、7は `{{UNIT_3_3}}`、8は `{{UNIT_3_4}}`）
