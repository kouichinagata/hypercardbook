# PapeRobo での書類の送り方（仕様）

非公開は非公開のまま。リンクを知っている人は誰でも読める、という例外は作らない。

## 1. 「Cardを追加」「Bookを追加」「HyperContentを追加」（添付）

- 送るのは**コピー**。画像やテキストファイルと同じ。
- 受け取った人が編集しても、送った人の元の書類は変わらない。
- 受け取った人は、HyperCardBook のユーザー（PapeRobo で受け取る人は必ずそう）。
- 3つとも同じ動き。署名欄のある書類でも、「サインをもらう」で送ったものでなければ、普通のコピー。
- 受け取った側の画面で、サインの流れ（承認ダイアログ）か、追加ボタンかを決めるのは、**どのメニューから送ったか**だけ。添付データの `signRequest`（「サインをもらう」で送るときだけ付く印）と、証明書の `certificateId` で伝える。書類の中身は見ない。

## 2. 自分の MiniApp を自分の PapeRobo で開く

- 15分チケットで開く。チケットの確認はページを読み込むときの1回だけで、遊んでいる間は止まらない。
- 非公開の MiniApp が UUID の URL だけで開ける例外（`loadUnlistedMiniApp`）は、なくす。

## 3. 「相手にサインをもらう（契約書等）」

1. 送るときに、選んだテンプレートから**送信者の契約書**（`contract_source_id` 付き、非公開）を作る。テンプレート本体は送らない。すでに契約書を選んだ場合は、その契約書をそのまま送る（`read-contract`）。
2. 相手は、PapeRobo から開いた契約書に入力・サインする。サインは送信者の契約書に表示される。
3. 開くときのチケットに、開いた人（`viewer`）が入る。署名の保存時にそのチケットを `x-paperobo-share` で送り、署名者の HyperCardBook ユーザー ID を `markdown_signatures.signer_id` に残す。
4. すべての署名欄がそろった時点で、送信者以外の署名者それぞれの本棚に、署名済みの契約書を非公開のコピーとして保存する（`copySignedContractToSigners`）。コピーの slug は `signed-<契約書ID>-<署名者ID>` で固定なので、二重には作られない。
5. テンプレートは所有者以外が保存できない（未署名のテンプレートへの保存は 401）。契約書はテンプレートではないので、相手は保存できる。

## 実装状況

| 項目 | 状況 |
|---|---|
| 3（契約書の作成・署名者の記録・完了時のコピー） | 実装済み（HyperCardBook） |
| 1（添付はコピー） | 実装済み。「HyperCardBookに追加」は、添付に入っている中身（`source`）を保存する。元が非公開でも、なくなっていても保存できる（PapeRobo の `/api/hyper-documents` と HyperCardBook の `add`）。追加ボタンは、受け取った人にだけ出る（署名依頼と証明書を除く） |
| 2（MiniApp はチケットで開く） | 実装済み。PapeRobo の `MiniAppFrame` が、自分の MiniApp（UUID）を `open-miniapp` で取ったチケット付き URL で開く。UUID の例外（`loadUnlistedMiniApp` と、URL 登録での非公開 MiniApp の追加）は削除した |

注意: 他人の非公開 MiniApp は、URL を知っていても、一覧に追加することも開くこともできなくなった。

## 変えないこと
- 署名のページ（`/hypercard/<id>/sign`）は、URL を知っている人なら誰でも署名・入力できる。メールなどでサインをお願いするときに使うため。
